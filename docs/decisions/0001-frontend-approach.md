# 0001 — Frontend Approach

**Status:** Proposed
**Date:** 2026-11-08

## Context

We have 5 weeks (possibly 4) and two developers, one of whom is still learning Python. The MVP screens are mostly forms and lists: sign up, post a ride, search results, ride details, my trips.

## Options

1. **Flask + Jinja templates + vanilla JavaScript**
   - ✅ One language/framework to learn on the backend, no separate frontend build
   - ✅ Fastest path to working features
   - ❌ Less suited for very interactive UIs

2. **React frontend + Flask JSON API**
   - ✅ Component-based UI, common in industry
   - ❌ Both developers would need to learn React during the project
   - ❌ Extra setup: separate dev servers, CORS, build/deploy for two apps
